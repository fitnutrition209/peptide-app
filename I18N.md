# Peptide app — English/Spanish (i18n)

English in `index.html` stays the master copy. Spanish is an overlay. Any Spanish field that is missing falls back to English for that field.

## Where Spanish lives
- `es.json` is embedded in `index.html` between `/*ES_DATA*/ ... /*END_ES_DATA*/`, and it is also published in `data.json` under `"ES"`, so remote auto-updates carry both languages.
  - `ES.PEPTIDES[id]`, `ES.DOSING|LAB|SIDE|STORE[id]` hold the same field names as the English, translated. `id`, `name`, `aka`, `cat`, `ev`, `src` and `type` are never translated.
  - `ES.QUIZ_BANK[i]` is matched to the English quiz by index. `q`, `o` and `e` are translated; `a` (the correct-answer index) comes from English.
  - `ES.COMMUNITY[id].rows` holds the Spanish translation shown under the English text, labeled "Traducción (no oficial)". The English researchcfps.com text is always shown word for word and is NEVER replaced.
  - `ES.UI` holds the JS UI strings, categories, status labels and disclaimers (hand-written, in `ui_es.json`). `ES.STATIC` holds the static HTML blocks, keyed by their English innerHTML.
- Sources (titles and URLs) stay in their original language.

## Rules for future edits (weekday routine)
1. Edit English in `index.html` as usual.
2. Run `./publish.sh`. It runs `translate_es.py`, which uses **hand translations only** (`tr_cache.json`, keyed by the exact English string). Nothing is machine-translated. Any new or changed English string with no hand translation is listed in `es_missing.json`, and a WARNING with the count is printed; that field shows in English until it is translated.
3. To translate flagged text: for each English string in `es_missing.json`, add `"<exact English>": "<Spanish>"` to `tr_cache.json` (keep the HTML, citation `<sup>` blocks and links exactly as in the English), then rerun `./publish.sh`. The original bulk translation lives in `hand/es00–es10.tsv` (indexed against the frozen `hand/items_v1.json`; compact tokens: `[c:1,2]` citation block, `[a:27]` source link, `<A>` external link, `{MACRO}` from `hand/macros.json`). `python3 hand/build_cache.py` rebuilds those entries, checks citation numbers, digits and tag counts against the English, and keeps any entries you added directly.
   - Community dosing rows: add a hand translation to `community_es.json`.
   - New static HTML text: add its English innerHTML to `static_en.json`. Hand overrides go in `ui_es.json` under `__STATIC_OVERRIDES__`.
   - New JS UI strings: wrap them in `L("...")` and add them to `ui_es.json`.
4. Quiz Spanish is matched by index. If you insert or delete quiz questions, the translations regenerate from the cache automatically when `translate_es.py` runs, so always run `publish.sh` after edits.
5. Never translate numbers, units, dates, drug names or citation numbers. Never add, drop or soften facts.

All Spanish content was hand-translated (fluent Latin American Spanish, pharmacy/regulatory register) in October 2026, replacing the earlier machine translation. Community dosing stays verbatim English with an unofficial translation.

## Terminology (keep consistent)
- compounding → preparación magistral; compounding pharmacy → farmacia de preparación magistral; compounded → de preparación magistral
- FDA Category 2 → Categoría 2 de la FDA (sustancias con posibles riesgos de seguridad)
- investigational → en investigación; research use only → solo para uso en investigación
- 503A bulks list → lista de sustancias a granel 503A; boxed warning → advertencia en recuadro
- label → etiqueta (de la FDA); enforcement discretion → discrecionalidad regulatoria
- WADA → AMA (WADA); gray market → mercado gris; beyond-use date → fecha límite de uso; GMP → BPF (GMP)
- Numbers keep English decimal points (0.25 mg), as is usual in Mexico and much of Latin America.

## "Not FDA-Approved" section (added Oct 21, 2026)
Content lives in the `NOTFDA` const in index.html (between `/*NOTFDA*/` and `/*END_NOTFDA*/`) and ships in data.json, so it auto-updates. The EN+ES source text is in `notfda/content.py`; run `python3 notfda/apply.py` to re-inject it (it also writes the ES pairs into tr_cache.json), then `./publish.sh`.
